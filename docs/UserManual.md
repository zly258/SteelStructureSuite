# 参数化钢结构套件 (SteelStructureSuite) 详细使用说明书

> 适用版本：AutoCAD 2019 ~ 2024（x64）。本仓库随附的二进制面向 AutoCAD 2019 / AutoCAD Plant 3D 2019 编译；面向 2021 及以上版本请用对应版本的 AutoCAD 托管程序集重新编译（见 README「四、编译」）。

## 一、快速加载与界面概览
**方式一：安装包（推荐）**：运行 `SteelStructureSuite-<版本>-setup.exe`，安装完成后重启 AutoCAD，插件会从 `C:\ProgramData\Autodesk\ApplicationPlugins\SteelStructureSuite.bundle` 自动加载。

**方式二：开发调试**：
1. 使用 Visual Studio（配置：`Debug | x64`）编译 `SteelStructureSuite.sln`，生成 `SteelStructureSuite.dll`。
2. 打开 AutoCAD 2019，在命令行输入 `NETLOAD` 并加载 `SteelStructureSuite.dll`。
3. 加载完成后，顶部自动激活 **「参数化钢结构」** 选项卡，包含 9 个面板：

   | 面板 | 内容 |
   | --- | --- |
   | **构建管理** | 模型管理、截面管理 |
   | **厂房框架** | 单跨门架、多跨门架、人字撑、双层管廊、装置框架、屋面桁架 |
   | **平台梯道** | 连续绘制、四柱平台、悬臂托架、悬挑走道、管廊桁桥、直跑斜梯、护笼直梯、螺旋盘梯、安全栏杆 |
   | **化工设备** | 塔器平台、塔器裙座、管道管托、罐顶栏杆、容器鞍座 |
   | **电力冶金** | 变电构架、电缆支架、重吊车梁、柱间支撑 |
   | **单根型钢** | 直线型钢、弧形型钢、螺旋型钢、编辑参数 |
   | **定位复写** | 三维对齐、阵列复制、归零、夹点复写开关 |
   | **图纸工具** | 批量 DWG 转 DXF、按范围合并多张 DWG |
   | **统计出图** | 材料统计、图纸生成、关于 |

   若未自动出现，执行命令 `SS_RIBBON`。
4. **关于**：点击「统计出图」面板中的【关于】按钮或执行 `SS_ABOUT`，可查看版本、版权与 MIT 许可证信息。

## 二、全图模型管理器（左树右表，定位高亮）
* **命令**：`SS_MANAGER`（或点击 Ribbon【模型管理】按钮）
* **功能**：
  * **左侧树状图**：按构件类型自动归类统计全图所有参数化钢结构，并展开显示每个位号。
  * **右侧属性表**：显示位号、类型、控制尺寸、主截面、材质、重量与三维坐标。
  * **定位高亮**：双击表格任意行或点击【定位高亮】，视口自动平滑缩放聚焦至该构件，并在模型空间中将其高亮选中。
  * **编辑 / 出图 / 删除**：可在管理器中直接修改选中构件参数、生成标准图框详图或删除构件。

## 三、单构件专属紧凑建模界面（带尺寸动态示意图 + 材料清单 Tab）
点击任意具体构件按钮（如 `单跨门架`、`直跑斜梯`、`安全栏杆` 等），均弹出该构件专属的紧凑建模窗口：
* **「参数与示意」标签页**：上方示意图固定不动，实时绘制当前构件的**二维工程示意图（带动态尺寸标注）**。窗口高度不够时，只滚动下方参数，底部按钮始终可见。参数区只显示该构件实际使用的尺寸与截面（自动隐藏无关项）。
* 截面下拉的初始值是该构件的预设规格。换一种构件不会沿用上一种的截面。
* **「材料清单」标签页**：实时计算并显示该构件的 `#1, #2...` 零件明细与总重。
* **两种零卡顿放置方式**（仅对栏杆、直跑斜梯、单根型钢、悬挑走道、管廊桁桥开放；框架、平台、梯子等类型自动只保留单点放置）：
  1. **【单点放置】**：三维结构轮廓以 60FPS 实时跟随光标，且与最终实体尺寸、方向 100% 吻合，点击即落位。
  2. **【两点线性绘制】**：拾取起点与终点，实时动态拉伸跨度/栏杆长度/斜梯长度，并自动沿两点方向旋转对齐。
  3. **【连续绘制】(`SS_LINEAR_CHAIN`)**：像绘制多段线一样连续拾取多个折点，快速生成首尾相连的多段安全栏杆、走道、钢梁或管廊桁桥；直跑斜梯等不可连续拼接的构件不会出现在连续绘制类型列表中。

弧形型钢只保留「选择圆弧」，螺旋型钢只保留「选择螺旋线」。截面沿选中的圆弧、圆或螺旋线连续扫掠，不再按折线拼接。塔器环梁、罐顶栏杆、鞍座弧板、管托弧板、护笼箍和螺旋盘梯的曲线杆件同样按整段路径扫掠。

## 四、正交夹点拉伸逻辑（修改单一参数，绝不重置其他参数）
选中模型空间中的三维钢结构后，提供互不干扰的正交参数夹点：
* **原点夹点**：仅整体平移构件位置。
* **长度/跨度夹点**：沿构件主轴方向正交投影，**仅修改跨度/长度 (`Span`)**，绝不改变旋转角、高度、宽度或截面规格。
* **高度夹点**：沿 Z 轴方向拉伸，**仅修改高度 (`Height`)**。
* **宽度/进深夹点**：沿构件横向正交投影，**仅修改宽度/进深 (`Length`)**。
* **复写开关**：`SS_OVERRULE_ON`（开启夹点复写）、`SS_OVERRULE_OFF`（关闭夹点复写）。
* **初始预设**：每种构件打开时使用自己的默认尺寸和截面。界面只会记住该构件类型上次用过的截面，不会套到其他构件上。
* **重置设置**：命令 `SS_RESETSETTINGS`（或 Ribbon【重置设置】）清除窗口位置、截面记忆、出图和图纸工具选项。截面库不受影响。

## 五、A1~A4 标准图框消隐详图出图
* **命令**：`SS_DRAWING`（或点击 Ribbon【施工详图】按钮）
* **核心特性**：
  * **标准图框**：支持选择国家标准 **A1、A2、A3、A4** 图框；比例默认「自动匹配标准比例」，按构件实测视图范围与材料表高度选择最合适的 1:1/1:2/1:5/1:10… 标准比例，也可手动指定。
  * **自适应排版**：正立面、侧立面和轴测图排在顶排，平面图与材料表排在底排，全部按实测轮廓尺寸定位并预留尺寸/标题空间，不会超出内外图框。
  * **清爽标注规范**：**只在轴测图标注 `#1, #2...` 序号引线**（沿视图外围均匀成环、按角度避让，底部让开图名；与右下角材料明细表件号一一对应，件号匹配不可靠时不标引线，避免错标）；**平面图与正/侧立面图只标注标准尺寸**，尺寸紧贴视图布置。
  * **字体标准**：全部采用 **宋体 (`SimSun`)，字高 `3.5 × 比例`，宽度因子 `0.8`**。
  * **双目标输出**：既可在**当前图纸拾取点**生成，也可**单独创建新 DWG 文件**并自动在 AutoCAD 中打开。

### 6.2 参数含义

所有构件共用同一套参数模型（截面与材质由全局截面库驱动），下表列出各构件中通用参数（跨度 `Span` / 长度 `Length` / 高度 `Height` / 次高 `SubHeight` / 数量 `BayCount`）的行业含义。

| 构件 | Span | Length | Height | SubHeight | BayCount |
| --- | --- | --- | --- | --- | --- |
| 塔器环形检修平台 | 塔器直径 | 平台宽度 | 牛腿悬挑高度 | **包角（°）** | — |
| 立式塔器钢裙座 | 裙座外径 | 底环板宽度 | 裙座高度 | 检查孔直径 | **竖向加劲筋数量** |
| 化工管道加劲管托 | 管道外径 | 管托长度 | 管道中心标高 | 底板宽度 | — |
| 储罐拱顶环形栏杆 | 储罐直径 | — | 栏杆高度 | **包角（°）** | — |
| 变电站 A 字龙门构架 | 构架跨度 | 柱脚横向张开 | 横梁标高 | 避雷针高度 | — |
| 电力电缆沟多层支架 | 沟段长度 | 托臂悬挑长度 | 立柱高度 | **层间距** | **托臂层数（2~6）** |
| 冶金重型吊车梁 | 吊车梁跨度 | 走道板宽度 | 梁高 | 加劲肋间距 | — |
| 冶金柱间交叉支撑 | 柱距 | 柱截面宽度 | 柱全高 | 吊车梁牛腿标高 | — |

> 包角类构件（塔器平台、罐顶栏杆）当 `SubHeight` ≥ 355° 时自动按**全周闭合**生成，否则按扇形生成；包角最小 60°。

### 6.3 构造细节

* **塔器环形检修平台**：按包角自动布设放射状悬挑牛腿主梁与牛腿斜撑杆，内、外弧形环梁连续闭合，外环立柱 + 连续圆弧双层安全扶手（GB 4053.3 高度 1050mm）。
* **立式塔器钢裙座**：裙座圆筒体 + 侧面管道引出检查孔（布尔开孔）+ 地脚螺栓基础底环板（Base Ring）+ 环向均匀分布的竖向加劲筋板。
* **化工管道加劲管托**：底部滑动底板、纵向主腹板、横向双加劲肋板、顶部弧形承重鞍板与重型双螺栓管卡。
* **储罐拱顶环形栏杆**：等距立柱 + 连接法兰底板 + 连续圆弧顶部扶手 + 中部横杆。
* **变电站 A 字型龙门构架**：双侧 A 字型双肢钢管斜腿柱、水平横隔杆、顶部三角形空间格构挂线横梁、柱顶避雷针架与独立法兰底板。
* **电力电缆沟多层支架**：等距预埋槽钢立柱、预埋锚固板、2~6 层可调悬臂角钢托臂、底部纵向贯通 `-50×5` 接地扁钢汇流排。
* **冶金重型吊车梁**：大截面焊接工字梁（上下翼缘 + 主腹板）、成对竖向加劲肋、外侧制动走道花纹板与边梁、顶部 QU 重型起重机钢轨、端部防撞车挡。
* **冶金柱间交叉支撑**：两端厂房主柱、柱顶刚性系杆、吊车梁牛腿标高处的中部刚性系杆、上柱与下柱双层十字交叉斜撑、中央节点连接板。

## 七、图纸批处理

### 7.1 批量 DWG 转 DXF
* **命令**：`SS_DWG2DXF`（Ribbon【图纸工具 → 批量转DXF】）
* 可一次加入多张 DWG，指定输出目录，并选择当前 AutoCAD 能写出的 DXF 版本（R12、2000、2004、2007、2010、2013、2018；若宿主版本另有更新格式，会自动出现在列表中）。
* 已在 AutoCAD 中打开的图纸按内存内容导出，未打开的图纸直接读取，不切换当前图形。
* 同名 DXF 默认跳过，勾选「覆盖已有 DXF」后重写。

### 7.2 合并多张 DWG
* **命令**：`SS_DWGMERGE`（Ribbon【图纸工具 → 合并图纸】）
* 按列表顺序读取每张图的**模型空间范围**，横向从左到右、或纵向从下到上依次排开，间距可填 0。
* 默认每张图放入一个同名图块，便于再移动；勾选「分解到模型空间」后炸成普通图元。
* 不合并图纸空间。输出文件不能与源文件同名，也不能是当前已打开的图。
