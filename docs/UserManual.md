# 参数化钢结构套件 (SteelStructureSuite) 详细使用说明书

> 适用版本：AutoCAD / AutoCAD Plant 3D **2019 ~ 2026（x64）**。安装包与绿色 Bundle 已内置 R23（2019~2020 / .NET 4.8）、R24（2021~2024 / .NET 4.8）、R25（2025~2026 / .NET 8.0）三个运行时模块，随宿主 CAD 版本自动匹配加载。

## 一、快速加载与界面概览
**方式一：安装包（推荐）**：运行 `SteelStructureSuite-<版本>-setup.exe`，安装完成后重启 AutoCAD，插件会从受信任目录 `C:\Program Files\Autodesk\ApplicationPlugins\SteelStructureSuite.bundle` 自动加载。

**方式二：开发调试**：
1. 使用 Visual Studio 2022（配置：`Debug | x64`）或 `pwsh tools/Publish.ps1 -Install` 编译部署。
2. 打开 AutoCAD（2019 ~ 2026），在命令行输入 `NETLOAD` 加载对应版本 `SteelStructureSuite.dll`（或直接通过 Bundle 自动加载）。
3. 加载完成后，顶部自动激活 **「参数化钢结构」** 选项卡，默认采用**极简菜单**（6 个统一配色面板，可在【帮助 → 详细菜单/极简菜单】或 `SS_RIBBONMODE` 随时切换）：

   | 面板 | 内容 |
   | --- | --- |
   | **构建管理** | 模型管理、截面管理、位号顺号、编辑参数、重置设置 |
   | **构件模板** | 模板管理（左树右表+检索+导入导出）、存为模板 |
   | **参数化构件** | 单根型钢 → 厂房框架 → 平台梯道 → 化工设备 → 电力冶金 → 区域组合（6 大类下拉菜单，共 34 种构件） |
   | **定位复写** | 连续绘制、三维对齐、阵列复制、标高归零、开启/关闭夹点复写 |
   | **统计出图** | 材料统计、施工详图、批量出详图、批量转 DXF、合并图纸 |
   | **帮助** | 使用说明、详细菜单/极简菜单切换、关于 |

   若未自动出现，执行命令 `SS_RIBBON`。
4. **关于**：点击「帮助」面板中的【关于】按钮或执行 `SS_ABOUT`，可查看版本、版权与 GNU GPL v3.0 开源许可证信息。

## 二、模型管理、位号顺号与截面库管理
### 2.1 全图模型管理器（`SS_MANAGER`）
* **左侧树状图**：按行业大类与构件类型自动归类统计全图所有参数化钢结构，并展开显示每个位号。
* **顶部实时检索**：支持按位号、类型、主截面、材质、控制尺寸与坐标模糊筛选，与左侧分类树实时联动。
* **定位高亮 / 编辑 / 出图 / 删除**：双击表格任意行或点击【定位高亮】，视口自动平滑缩放聚焦并高亮该构件；可直接编辑参数、生成详图或删除构件。

### 2.2 独立位号顺号重排（`SS_RENUMBER`）
* 点击功能区「构建管理 → **位号顺号**」或执行 `SS_RENUMBER` 打开独立顺号窗口：
  * **三种处理策略**：`强制统一前缀并顺号`（默认）、`仅强制统一前缀(保原号)`、`仅顺号(保留原前缀)`。
  * **可配编号规则**：支持设置编号位数（2 / **3 位默认如 `001`** / 4 / 5 位）、起始号、连接符（`-` / `_` / 无）、编号范围（按类型分别顺号 / 全图统一顺号）与排序顺序（坐标 X→Y→Z / Y→X→Z / 原位号）。
  * **按类型前缀预设**：内置全部 26 种构件类型的默认前缀，可取消勾选“仅显示当前图已有类型”查看并修改全部预设，点击【保存前缀预设】后新建构件与顺号均自动采用。
  * **前后对比预览**：右侧实时展示原位号 → 新位号与状态（`统一前缀+顺号` / `统一前缀` / `顺号调整` / `无变化`），支持逐项勾选与【仅选前缀不符】快捷筛选。

### 2.3 型钢截面库管理（`SS_SECTIONS`）
* **5 大类 24 种截面（176 条预置规格）**：涵盖热轧标准型钢、焊接与组合型钢、冷弯薄壁型钢、空心钢管、实心型材与板材，左侧分类树 + 右侧搜索表格 + 底部三行分区编辑表单 + 2D 实时轮廓预览。
* **国标手册值与手动修正**：热轧标准型钢预置 GB/T 11263 / GB/T 706 手册截面积、单重与表面积（含圆角弧度），支持界面直接手工修改或点击【按公式重算】恢复公式计算。
* **数据存储路径与格式**：
  * 插件默认模板位于安装目录 `Contents\Data\DefaultSectionCatalog.csv`。
  * 首次启动自动生成用户本地文件 `%LocalAppData%\SteelStructureSuite\SectionCatalog_MultiTable.csv`（UTF-8 with BOM，14 列 CSV，可直接用 Excel 打开备份或编辑），界面底部提供【打开目录】按钮一键定位。
  * 支持按 5 大类工作表批量导出/导入 `.xlsx` 与 `.csv`。

## 三、单构件两列可调建模界面（轴测示意图 + PropertyGrid 参数 + 材料清单 Tab）
点击任意具体构件按钮（如 `单跨门架`、`直跑斜梯`、`钢平台成套` 等），均弹出该构件专属建模窗口：
* **「参数与示意」标签页**：中间内容区为**两列可调布局**（带可拖拽 `GridSplitter` 并记忆比例）——左侧实时绘制当前构件的**单幅三维轴测示意图**（含三维尺寸标注与 XYZ 坐标指示），右侧为按类别分组的 `PropertyGrid` 参数表（截面项内置可检索树形下拉）。
* 截面记忆按构件类型成对保存「截面类型 + 截面代号」，切换不同构件不会互相串用。
* **参数模板（自带 3 种预设 + 真实自定义模板）**：参数区「参数模板」下拉同时提供该构件自带的 3 种 `[内置]` 预设与真实用户模板（`[模板]` / `[通用]`）：
  * **【存为模板】**：在窗口内就地填写名称与备注，把当前全部参数（含截面类型 + 截面代号）保存到 `%LocalAppData%\SteelStructureSuite\Templates.json`。
  * **【管理】**：打开参数模板管理窗口，**左侧按分类树筛选，右侧表格显示模板并支持模糊检索**、双击修改名称/备注、`MessageBox` 删除确认及 JSON 导入导出。
* **「材料清单」标签页**：实时计算并显示该构件的 `#1, #2...` 零件明细与总重。
* **两种零卡顿放置方式**（仅对栏杆、直跑斜梯、单根型钢、悬挑走道、管廊桁桥开放；框架、平台、梯子等类型自动只保留单点放置）：
  1. **【单点放置】**：三维结构轮廓动态实时跟随光标，且与最终实体尺寸、方向 100% 吻合，点击即落位。
  2. **【两点线性绘制】**：拾取起点与终点，实时动态拉伸跨度/栏杆长度/斜梯长度，并自动沿两点方向旋转对齐。
  3. **【连续绘制】(`SS_LINEAR_CHAIN`)**：像绘制多段线一样连续拾取多个折点，快速生成首尾相连的多段安全栏杆、走道、钢梁或管廊桁桥；直跑斜梯等不可连续拼接的构件不会出现在连续绘制类型列表中。

弧形型钢只保留「选择圆弧」，螺旋型钢只保留「选择螺旋线」。截面沿选中的圆弧、圆或螺旋线连续扫掠，不再按折线拼接。塔器环梁、罐顶栏杆、鞍座弧板、管托弧板、护笼箍和螺旋盘梯的曲线杆件同样按整段路径扫掠。

## 四、正交夹点拉伸逻辑（修改单一参数，绝不重置其他参数）
选中模型空间中的三维钢结构后，提供互不干扰的正交参数夹点：
* **原点夹点**：仅整体平移构件位置。
* **长度/跨度夹点**：沿构件主轴方向正交投影，**仅修改跨度/长度 (`Span`)**，绝不改变旋转角、高度、宽度或截面规格。
* **高度夹点**：沿 Z 轴方向拉伸，**仅修改高度 (`Height`)**。
* **宽度/进深夹点**：沿构件横向正交投影，**仅修改宽度/进深 (`Length`)**。
* **复写开关**：`SS_OVERRULE_ON`（开启夹点复写）、`SS_OVERRULE_OFF`（关闭夹点复写）。
* **初始预设**：每种构件打开时使用自己的默认尺寸和截面。界面只会记住该构件类型上次用过的截面，不会套到其他构件上。
* **重置设置**：命令 `SS_RESETSETTINGS`（或 Ribbon【重置设置】）清除窗口位置、截面记忆、出图和图纸工具选项。截面库不受影响。

## 五、A1~A4 标准图框消隐详图出图
* **命令**：`SS_DRAWING`（或点击 Ribbon【施工详图】按钮）——仅支持单个构件。可先预选一个构件，或按提示单击拾取；程序会校验对象是否为本插件生成的带参数钢结构，校验通过后弹出出图设置窗。出图设置也可单独用 `SS_DRAWCFG`（Ribbon【出图设置】）打开。
* **核心特性**：
  * **标准图框**：支持选择国家标准 **A1、A2、A3、A4** 图框；比例默认「自动匹配标准比例」，按构件实测视图范围与材料表高度选择最合适的 1:1/1:2/1:5/1:10… 标准比例，也可手动指定。
  * **自适应排版**：正立面、侧立面和轴测图排在顶排，平面图与材料表排在底排，全部按实测轮廓尺寸定位并预留尺寸/标题空间，不会超出内外图框。
  * **清爽标注规范**：**只在轴测图标注带圆圈的原生 `MLeader` 件号引线**（标准扁平工程箭头，圆圈与引线作为一个整体对象可整体拖拽；按锚点左右分列等距排布且互不交叉，与右下角材料明细表件号一一对应）；**正立面、侧立面与平面图不标件号，仅标三道等距整齐排列的详细尺寸**（分跨/分层链式尺寸 + 轴线总尺寸 + 外包总尺寸）。
  * **高精度防锯齿出图**：圆管/圆钢按 64 边形高精度细分，共线合并容差收紧至 `0.15mm` 且未合并段保留精确原始端点，彻底消除圆弧锯齿与断口。
  * **材料表合并**：明细表不显示“部位”列；截面规格、材质、单长相同的零件自动合并为一行，数量与重量累加。
  * **字体标准**：全部采用 **宋体 (`SimSun`)，字高 `3.5 × 比例`，宽度因子 `0.8`**。
  * **双目标输出**：既可在**当前图纸拾取点**生成，也可**单独创建新 DWG 文件**并自动在 AutoCAD 中打开。

### 5.1 批量出详图（`SS_BATCHDRAW`）
一次框选多个构件批量出图，适合整片厂房或整套装置。
* **图纸复用**：几何参数、三个截面、材质、构件类型完全一致的构件视为同一规格，**只出一张图**，图名注明「ST-101、ST-102、ST-103 等 N 件」。位号与插入点不参与判定，浮点误差已归一。可在窗口里关闭复用，改为每件一张。
* **附加内容**：自动生成**图纸目录表**（图号/图名/图幅/比例/数量/合计）与**汇总材料表**；每张图还可带接头局部放大图。
* **输出目标**：可写入**当前 DWG**（按网格自动排布）或**新建 DWG 文件**。
* **进度与取消**：窗口实时显示进度条、`3/12（25%）正在生成…` 文字与带时间戳的滚动日志。点【取消】会在**当前这张图完成后**停止，已生成的图纸保留并照常保存，不会产生半张损坏的图。

### 6.3 构造细节

* **塔器环形检修平台**：按包角自动布设放射状悬挑牛腿主梁与牛腿斜撑杆，内、外弧形环梁连续闭合，外环立柱 + 连续圆弧双层安全扶手（GB 4053.3 高度 1050mm）。
* **立式塔器钢裙座**：裙座圆筒体 + 侧面管道引出检查孔（布尔开孔）+ 地脚螺栓基础底环板（Base Ring）+ 环向均匀分布的竖向加劲筋板。
* **化工管道加劲管托**：底部滑动底板、纵向主腹板、横向双加劲肋板、顶部弧形承重鞍板与重型双螺栓管卡。
* **储罐拱顶环形栏杆**：等距立柱 + 连接法兰底板 + 连续圆弧顶部扶手 + 中部横杆。
* **变电站 A 字型龙门构架**：双侧 A 字型双肢钢管斜腿柱、水平横隔杆、顶部三角形空间格构挂线横梁、柱顶避雷针架与独立法兰底板。

## 七、图纸批处理

### 7.1 批量 DWG 转 DXF
* **命令**：`SS_DWG2DXF`（Ribbon【图纸工具 → 批量转DXF】）
* 可一次加入多张 DWG，指定输出目录，并选择当前 AutoCAD 能写出的 DXF 版本（R12、2000、2004、2007、2010、2013、2018；若宿主版本另有更新格式，会自动出现在列表中）。
* 已在 AutoCAD 中打开的图纸按内存内容导出，未打开的图纸直接读取，不切换当前图形。
* 同名 DXF 默认跳过，勾选「覆盖已有 DXF」后重写。

### 7.2 合并多张图纸
* **命令**：`SS_DWGMERGE`（Ribbon【图纸工具 → 合并图纸】）
* 按列表顺序读取每张 DWG 或 DXF 的**模型空间范围**，横向从左到右、或纵向从下到上依次排开，间距可填 0。输出扩展名用 `.dwg` 或 `.dxf`。
* 默认每张图放入一个同名图块，便于再移动；勾选「分解到模型空间」后炸成普通图元。
* 不合并图纸空间。输出文件不能与源文件同名，也不能是当前已打开的图。
